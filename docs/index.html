Startup Gyaan Uploader

An internal tool used only by the owner of the YouTube channel Startup Gyaan Daily to upload short clips to that channel.

It has one user (the channel owner) and does not offer sign-in to anyone else.

Instagram: @startupgyaan.daily

This tool uses YouTube API Services to upload videos to the owner's YouTube channel.
