Privacy Policy: Startup Gyaan Uploader

Last updated: 10 November 2026

Startup Gyaan Uploader is a private tool used only by the owner of the YouTube channel Startup Gyaan Daily. It uploads videos that the owner has edited to the owner's own channel.

What it accesses

It requests one Google permission, youtube.upload, for the owner's own account. It uses that permission only to upload videos and set their title and description.

What it does not do

  • It does not let anyone else sign in.
  • It does not read, collect, store, sell or share personal data about any user or viewer.
  • It does not read watch history, comments, subscribers or analytics.

Storage

The owner's sign-in token is stored only as an encrypted secret in the owner's own GitHub account, to run the uploads. Nothing else is stored.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions.
